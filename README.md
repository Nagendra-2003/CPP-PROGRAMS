## ⚙️ How to Run

### 1. Clone the Repository

```bash
git clone https://github.com/Nagendra-2003/CPP-PROGRAMS.git
```

### 2. Open the Repository Folder

```bash
cd CPP-PROGRAMS
```

### 3. Compile a C++ Program

```bash
g++ program.cpp -o program
```

### 4. Run the Program

On Windows:

```bash
program.exe
```

On Linux or macOS:

```bash
./program
```

**Note:** Replace `program.cpp` with the name of your actual C++ source file.
